# Preetham V R — Personal Portfolio

A high-performance, dark-aesthetic brutalist personal portfolio engineered for **Preetham V R**, specializing in Applied AI, Machine Learning, and Data Analytics.

Inspired by modernist Swiss & brutalist editorial design (e.g. Christen Dijoux), featuring dynamic 3D dithered canvas particle spheres, interactive project case studies, an interactive AI Assistant chatbot, live IST local clock, audio synthesis micro-interactions, negative high-contrast display mode, and responsive layout for all screen sizes.

---

## ⚡ Quick Start / Run Locally

### Option 1: Local HTTP Server (Python) — Currently Active
Run the built-in HTTP server from the project directory:
```bash
python -m http.server 3000
```
Open **[http://localhost:3000](http://localhost:3000)** in any modern web browser.

### Option 2: Node.js / npx
```bash
npx serve . -p 3000
```

### Option 3: Direct Browser File
Double-click `index.html` or open it directly in Google Chrome, Microsoft Edge, Firefox, or Safari.

## 🚀 Deployment to GitHub Pages

1. Create a public repository on GitHub named `preetamvr1595.github.io` (or push to your existing repository).
2. Push `index.html`, `style.css`, and `script.js` to the repository root.
3. In GitHub repository settings: **Settings → Pages → Build and deployment → Branch: `main` → Folder: `/ (root)` → Save**.
4. The live site will be accessible at:
   **`https://preetamvr1595.github.io/`**
