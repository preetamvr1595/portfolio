## 🔬 Interactive 3D Dithered Particle Sphere

The hero centerpiece features a custom-engineered particle sphere rendered at 60 FPS on an HTML5 `<canvas>`:

```
          . - ~ ~ ~ - .
      . '   *   ·   *   ' .        Formula:
    /   ·   *     *   ·   \      θ = arccos(1 - 2i / N)
   :  *   \    |    /   *  :     φ = π * (1 + √5) * i
  :   ·    \   |   /    ·   :    x = R · sin(θ) · cos(φ)
  :   *     ── O ──     *   :    y = R · sin(θ) · sin(φ)
   :  ·   /    |    \   ·  :     z = R · cos(θ)
    \   *     *   ·   *   /
      . '   ·   *   ·   ' .
          ' - . _ . - '
```

- **Fibonacci Spiral Distribution**: Guarantees equidistant particle separation on spherical geometry.
- **Euler Angle Rotations**: Dynamic 3-axis rotation with responsive velocity inertia and cursor tracking.
- **Dithered Depth Projection**: Opacity and point radius scale dynamically based on calculated Z-depth.

# 3. Start local HTTP server
